# homebrew-tap

Personal Homebrew tap. One formula, `browser-router`, which source-builds https://github.com/sjdonado/browser-router: no bottle, no binary download.

```sh
brew install sjdonado/tap/browser-router
```

Then follow the caveats it prints: copy the bundle to `~/Applications`, register it, seed the config if there is none, and open it once to become the default browser.
